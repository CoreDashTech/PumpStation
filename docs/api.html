REST API · สถานีสูบจ่ายน้ำ PIN6

API สำหรับเชื่อมต่อข้อมูล SCADA เข้ากับระบบอื่นขององค์กร (ERP, BI, BMS) ตาม TOR EN0013/2569 ข้อ 3.2.5 ใช้มาตรฐาน REST และข้อมูล JSON ไม่ผูกขาดกับผู้พัฒนา

Base URLhttps://scada.pin6.example (กำหนดจริงเมื่อส่งมอบ)
เวอร์ชันv1 — เส้นทางขึ้นต้นด้วย /api/v1
รูปแบบJSON (UTF-8) · เวลาเป็น ISO 8601 พร้อมเขตเวลา (+07:00)
SpecOpenAPI 3.0 (openapi.yaml) — นำเข้า Postman / Swagger UI ได้ทันที

การยืนยันตัวตน

ทุกคำขอต้องแนบ API Key ที่ผู้ดูแลระบบสร้างจากเมนู REST API ในระบบ เลือกแบบใดแบบหนึ่ง

X-API-Key: cdps_live_xxxxxxxxxxxxxxxxxxxxxxxx
# หรือ
Authorization: Bearer cdps_live_xxxxxxxxxxxxxxxxxxxxxxxx

คีย์แต่ละตัวกำหนดสิทธิ์ (scope) ได้ และยกเลิกสิทธิ์ได้ทันทีโดยไม่กระทบคีย์อื่น

Scopeอนุญาต
read:latest/latest, /points, /meta/last-update
read:history/history
read:status/devices/status
read:alarms/alarms

จำกัดจำนวนการเรียก

กำหนดได้ต่อคีย์ (30 / 60 / 120 / 600 ครั้งต่อนาที) ทุกคำตอบมี header

X-RateLimit-Limit: 60
X-RateLimit-Remaining: 57
X-RateLimit-Reset: 1794667380      # epoch seconds เมื่อโควตารีเซ็ต
Retry-After: 23                    # เฉพาะเมื่อได้ 429

รูปแบบข้อมูล

ค่าตัวเลขเป็นหน่วยตามจุดตรวจวัด quality บอกคุณภาพข้อมูล: good ปกติ, bad_comm ขาดการสื่อสารกับอุปกรณ์, uncertain ค่าไม่แน่นอน

ค่าล่าสุด

GET/api/v1/latestread:latest

GET/api/v1/historyread:history
พารามิเตอร์ชนิดคำอธิบาย
point *stringจุดตรวจวัด เช่น FT-01.flow
start *ISO 8601เวลาเริ่มต้น
end *ISO 8601เวลาสิ้นสุด (ต้องมากกว่า start)
intervalenumช่วงเวลารวมข้อมูล 1m 5m 15m 1h 1d (ค่าเริ่มต้น 5m)
aggenumวิธีรวม avg min max (ค่าเริ่มต้น avg)
ได้สูงสุด 10,000 จุดข้อมูลต่อคำขอ หากเกินจะได้ 400 RANGE_TOO_LARGE ให้เพิ่ม interval หรือแบ่งช่วงเวลา
curl -s "https://scada.pin6.example/api/v1/history?point=FT-01.flow&start=2026-11-13T00:00:00%2B07:00&end=2026-11-14T00:00:00%2B07:00&interval=1h&agg=avg" \
  -H "X-API-Key: $CDPS_KEY"
{
  "point": "FT-01.flow", "unit": "m3/h",
  "start": "2026-11-13T00:00:00+07:00", "end": "2026-11-14T00:00:00+07:00",
  "interval": "1h", "agg": "avg", "count": 24, "truncated": false,
  "data": [
    { "ts": "2026-11-13T00:00:00+07:00", "value": 96.412 },
    { "ts": "2026-11-13T01:00:00+07:00", "value": 88.905 },
    ...
  ],
  "meta": { "site": "PIN6", "generated_at": "2026-11-14T21:45:02+07:00" }

รายการจุดตรวจวัด

GET/api/v1/pointsread:latest

รหัสข้อผิดพลาด

{ "error": { "status": 429, "code": "RATE_LIMITED", "message": "เกินจำนวนการเรียกที่กำหนด 60 ครั้ง/นาที" } }
HTTPcodeสาเหตุแนวทางแก้
400INVALID_PARAMETERพารามิเตอร์ผิดรูปแบบตรวจ start/end/interval/agg
400RANGE_TOO_LARGEเกิน 10,000 จุดข้อมูลเพิ่ม interval หรือแบ่งช่วง
401UNAUTHORIZEDไม่ได้ส่ง API Keyแนบ X-API-Key
401INVALID_API_KEYคีย์ผิดหรือถูกยกเลิกขอคีย์ใหม่จากผู้ดูแลระบบ
403FORBIDDENคีย์ไม่มี scope ที่ต้องใช้ขอเพิ่ม scope
404POINT_NOT_FOUNDไม่พบจุดตรวจวัดดู GET /points
429RATE_LIMITEDเกินโควตาต่อนาทีรอตาม Retry-After
503DEVICE_OFFLINEอุปกรณ์ต้นทางขาดการสื่อสารลองใหม่ / ตรวจสถานะ
500INTERNAL_ERRORข้อผิดพลาดภายในแจ้งผู้ดูแลพร้อม X-Request-Id

ตัวอย่างโค้ด

Python

import requests
r = requests.get("https://scada.pin6.example/api/v1/latest",
                 params={"points": "system.pressure,FT-01.flow"},
                 headers={"X-API-Key": CDPS_KEY}, timeout=10)
r.raise_for_status()
for p in r.json()["data"]:
    print(p["point"], p["value"], p["unit"])

JavaScript

const res = await fetch("https://scada.pin6.example/api/v1/devices/status", {
  headers: { Authorization: `Bearer ${CDPS_KEY}` }
});
const { pumps } = await res.json();
console.table(pumps);
